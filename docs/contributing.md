# Contributing

Read the repository `CONTRIBUTING.md` before opening a change. Documentation is
reviewed with the same publication boundary as source.

For documentation changes:

1. edit Markdown or Mermaid source below `docs/`;
2. keep examples synthetic and use reserved names and address ranges;
3. run the strict MkDocs build, offline link/fragment checker and Mermaid parser;
4. never commit generated `site/` output;
5. update diagrams when a trust boundary or protocol transition changes.

Security issues belong in the private process described by repository
`SECURITY.md`, not in a public issue.
