# Glossary

| Term | Definition |
| --- | --- |
| AD CS | Microsoft Active Directory Certificate Services. |
| CA | Certificate authority that issues and revokes certificates. |
| CES | Certificate Enrollment Web Service used for restricted CA submission. |
| CMC | Certificate Management over CMS request/response structure used by WSTEP. |
| CSR / PKCS#10 | Public-key certificate request and proof material; it never grants authority by itself. |
| EAP-TLS | Network authentication using a client certificate. |
| Facts | Broker-authoritative asset attributes mapped to certificate claims and policy. |
| HSM | Hardware security module used for production key custody. |
| MS-WSTEP | Microsoft WS-Trust X.509 enrollment protocol. |
| MS-XCEP | Microsoft certificate enrollment policy protocol. |
| PKCS#11 | API boundary for a cryptographic token or HSM. |
| PKS2 | Versioned authenticated protocol between broker and isolated signer. |
| SAN | Subject Alternative Name certificate extension. |
| SPKI | SubjectPublicKeyInfo bytes that identify the requested public key. |
| WSTEP | The broker's native enrollment endpoint implementing the supported MS-WSTEP profile. |
| XCEP | The broker's native policy endpoint implementing the supported MS-XCEP profile. |
